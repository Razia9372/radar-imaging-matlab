# Radar Imaging with MATLAB

## Overview

This repository contains my MATLAB exercises and simulations related to radar imaging and signal processing.

The main objective is to develop a practical understanding of the mathematical foundations, signal processing techniques, and computational methods used in radar systems.

## Objectives

- Understand Fourier analysis and its applications in radar signal processing.
- Implement signal processing algorithms using MATLAB.
- Explore radar signal generation and analysis.
- Study range and Doppler processing.
- Investigate radar imaging and reconstruction techniques.

## Tools

- MATLAB
- Signal Processing Toolbox (where required)

## Exercises

| Topic | Description | Status |
|---|---|---|
| Fourier Analysis | CTFT, DFT, and FFT | In progress |
| Radar Signals | Signal generation and analysis | Planned |

| Doppler Processing | Velocity estimation | Planned |
| Radar Imaging | Imaging and reconstruction | Planned |

## Learning Approach

Each exercise aims to connect theoretical concepts with practical MATLAB implementations, numerical experiments, and visualization of results.
